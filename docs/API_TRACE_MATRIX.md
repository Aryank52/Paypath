## 1. Executive Summary

This API Trace Matrix establishes full traceability from the user interface down to database persistence, external provider calls (PayPal REST v2 and Google Gemini 2.5 Flash), and reciprocal frontend state updates. Every route has been audited to confirm:
- Authentication requirement (`OAuth2 Bearer` with JWT validation).
- Authorization / RBAC enforcement (`CUSTOMER`, `MERCHANT_ADMIN`, `PLATFORM_ADMIN`).
- Input validation via Pydantic v2 schemas.
- Transactional ACID integrity and audit event capture.
- Independent external read-back verification for financial mutations.

## 3. Data Integrity & Verification Invariants

Every financial mutation endpoint in the matrix above adheres to the following structural guarantees:
1. **Pre-Action Policy Gate:** No money-movement API call can be executed without an automated pre-flight policy evaluation passing deterministically.
2. **Dual-Phase Settlement Verification:** Any capture or refund executed via PayPal REST v2 is immediately validated through an independent read-back request (`/v2/payments/captures/{id}` or `/v2/payments/refunds/{id}`). Only after PayPal returns `COMPLETED` does the database transition to `VERIFIED`.
3. **Strict Zero-Trust RBAC:** Every user-specific query verifies ownership via `tx.user_id == current_user.id` or requires elevated `PLATFORM_ADMIN` permissions.
4. **Audit Immutability:** Every mutation automatically registers an entry in `audit_logs` capturing user ID, actor type, IP address, and payload delta.
